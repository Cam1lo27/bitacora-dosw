# Semana 2 – SOLID y Patrones de Software

## ¿Qué entendía mal antes?

- No tenía claro la diferencia entre un patrón 
y una simple organización de código.
- Confundía el uso de interfaces solo como 
una formalidad, no como una herramienta clave de diseño.
- No tenía presente el desarrollo e implementación de los
patrones vistos en los ejercicios de la semana.

## ¿Qué entiendo ahora?

- Entiendo que SOLID sirve para diseñar código más flexible,
mantenible y extensible, no solo para cumplir reglas.
- Ahora entiendo mas el desarrollo de los patrones Factory, 
Adapter y Memento
- Comprendí que separar responsabilidades evita modificar código 
que ya existe cuando se agregan nuevas funcionalidades.

## ¿Qué me falta reforzar?

- Necesito practicar y aprender a implementar el resto de 
patrones.
- Reconocer más rápido qué patrón aplicar según el 
problema planteado.
- Aplicar SOLID de forma natural y buena, aprender bien 
cada principio y adaptarlo cuando sea necesario.
