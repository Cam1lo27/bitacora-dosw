
# Semana 1

## ¿Qué entendía mal antes?

- No tenia presente que hacia anyMatch
- Pensaba que .peek() servía para “hacer algo”
  con los datos, no solo para verlos pasar.
- No tenía claro para qué servían las referencias
  a métodos (User::isActive) y cuándo usarlas.

## ¿Qué entiendo ahora?

- Entendí cómo combinar lambdas para transformar,
  filtrar y validar información.
- Ahora puedo leer un Stream de principio a fin y
  casi siempre entender qué está haciendo cada paso.
- Comprendo por qué peek() solo funciona si hay una
  operación terminal después.

## ¿Qué me falta reforzar?

- Escribir Streams más limpios y evitar que sean demasiado largos.
- Reconocer cuándo es mejor usar un Stream y cuándo un for
  tradicional.
- Trabajar más en expresiones lambda más claras y evitar que
  queden confusas.
