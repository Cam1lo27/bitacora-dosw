# Semana 3 – SOLID y Patrones de Software parte 2

## ¿Qué entendía mal antes?

- Pensaba que los patrones eran solo una forma organizada de escribir código, pero no entendía que realmente solucionan problemas comunes de diseño.

- Veía las interfaces como algo obligatorio, no como una herramienta clave para desacoplar clases.

- No relacionaba claramente los principios SOLID con la implementación práctica de los patrones.

- No distinguía bien cuándo usar herencia o composición.

## ¿Qué entiendo ahora?

- Entiendo que los patrones de software ayudan a crear código más flexible, mantenible y escalable.

- Comprendo que muchos patrones aplican directamente los principios SOLID para evitar acoplamientos innecesarios.

- Ahora veo que separar responsabilidades permite agregar nuevas funcionalidades sin modificar el código existente.

- Entiendo mejor cómo estructurar sistemas usando patrones creacionales, estructurales y de comportamiento según el problema.

## ¿Qué me falta reforzar?

- Practicar más la implementación de distintos patrones para ganar seguridad.

- Identificar con mayor rapidez qué patrón aplicar según el problema planteado.

- Aplicar los principios SOLID de manera más natural al diseñar soluciones.

- Mejorar mi capacidad de combinar varios patrones en un mismo sistema cuando sea necesario.
